### 关键结论（后续 Agent 必读）

1. **GLB 无 extras/userData**：讲义 P18 的 `userData.joint` 建表写法在本素材上返回 0 个关节，必须按名字找。
2. **关节轴是节点局部 +Y，不是 +Z**：Blender（Z-up）的局部 +Z 经 glTF（Y-up）重标定后成为 +Y；用 +Z 会整体差 90°。判据：J5 转动时 TCP 位置不变。
3. **驱动公式 `q = qZero · Ry(θ)`（右乘）**；`setRotationFromAxisAngle` 会覆盖 R_fix，不可用。
4. **单位 = 0.1 m/单位**（臂高约 1.35 m，默认 Box3 口径；`precise=true` 为 1.2175 m）；基座底面在 y=+0.1095 m，模型"悬空"是素材原点所致。
5. **零位 TCP = (-0.1601, 1.2491, -0.5127) m，q=(0,0,0,1)，RPY=0**（three.js 实测）。
6. **素材错代**：`robot_spec.yaml` / `robot.urdf` / `_glb_dump.json` / `*.pre-fix.bak` 描述旧模型；只有 `robot_articulated.glb` + `joint_map.json` 是当前数据。
7. **可达区域参考值**（N=2e5）：x∈[-0.42, 0.08]、y∈[-1.10, 2.00]、z∈[-1.62, 1.48] m；r 中位 0.95、max 2.14 m；x 宽只有 0.49 m。
