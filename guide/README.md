## 5. 本实验的"五个认知锚点"（做完应该能脱口而出）

1. **场景树就是运动链**：`matrixWorld = 父 × 局部`；只改一个关节的局部旋转，下游全部跟随，FK 由渲染管线免费完成。
2. **关节 = 常量 × 变量**：`R_fix`（qZero）是素材烘焙好的常量，唯一变量是绕局部轴的角；**右乘**才是绕自身轴。
3. **坐标系是第一杀手**：Blender Z-up → glTF Y-up，轴从 +Z 变 +Y；joint_map 的位置量也要换算 `(x, z, −y)`。
4. **单位是第二杀手**：素材 1 单位 = 0.1 m；不缩放就是 12 米巨物。
5. **示教编程 = 关节空间的艺术**：MOVJ 只需关节插值（无需 IK），所以路径不可控；要直线/圆弧就得笛卡尔插值 + 逐点 IK（实验二）。
